# 音声文字起こしアプリ

このアプリケーションは、ブラウザの音声認識機能を使用して、リアルタイムで音声を文字に変換し、テキストとして保存できるWebアプリケーションです。

## 機能

- **リアルタイム音声認識**: ブラウザの音声認識APIを使用して、話した言葉をテキストに変換
- **自動文字起こし**: 録音中は自動的に音声を認識し続け、テキストエリアに表示
- **CSVダウンロード**: 文字起こしされたテキストをCSV形式でダウンロード可能
- **クリップボードコピー**: テキストを簡単にクリップボードにコピー
- **ダークモード対応**: 目に優しいダークモードとライトモードの切り替え
- **レスポンシブデザイン**: スマートフォン、タブレット、デスクトップなど様々な画面サイズに対応
- **文字数カウント**: 文字起こしされたテキストの文字数をリアルタイム表示

## 使用方法

1. アプリを開き、「録音開始」ボタンをクリックします
2. マイクへのアクセス許可を求められた場合は「許可」をクリックします
3. 話し始めると、音声が自動的にテキストに変換されます
4. 録音を停止するには「録音停止」ボタンをクリックします
5. 文字起こしされたテキストをCSVとしてダウンロードするには「CSVダウンロード」ボタンをクリックします
6. テキストをクリップボードにコピーするには、テキストエリア右上の「コピー」ボタンをクリックします
7. テキストをクリアするには、テキストエリア右上の「クリア」ボタンをクリックします
8. ダークモードとライトモードを切り替えるには、画面右上のトグルスイッチをクリックします

## 技術仕様

- **フロントエンド**: HTML5, CSS3, JavaScript (ES6+)
- **音声認識**: Web Speech API (SpeechRecognition)
- **レスポンシブデザイン**: カスタムCSS、メディアクエリ
- **テーマ切り替え**: CSS変数とJavaScriptによる動的テーマ切り替え
- **ホスティング**: GitHub Pages

## ブラウザ対応

このアプリケーションは以下のブラウザで動作確認済みです：

- Google Chrome (推奨): バージョン 85 以上
- Microsoft Edge: バージョン 85 以上
- Firefox: 最新版（ただし一部機能に制限あり）

**注意**: Safari、Internet Explorer、および一部のモバイルブラウザでは、Web Speech APIがサポートされていないか、制限がある場合があります。最良の体験を得るには、Google Chromeの使用をお勧めします。

## プライバシーについて

- このアプリケーションは、ブラウザの音声認識APIを使用しています
- 音声データはブラウザ内で処理され、外部サーバーには送信されません
- 文字起こしされたテキストはローカルに保存され、ページを閉じると消去されます

## ローカルでの実行方法

ローカル環境で実行する場合は、以下の手順に従ってください：

1. このリポジトリをクローンまたはダウンロードします
   git clone https://github.com/[username]/voice-to-csv-transcriber.git

2. プロジェクトフォルダに移動します
   cd voice-to-csv-transcriber

3. ローカルサーバーを起動します（例：Python を使用する場合）
   # Python 3
   python -m http.server
   
   # Python 2
   python -m SimpleHTTPServer

4. ブラウザで http://localhost:8000 にアクセスします
